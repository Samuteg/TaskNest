A página do projeto (`/dashboard/$projectId`) exibe o quadro de tarefas com visualização Kanban.

## Colunas (Status)

| Coluna | Valor | Cor |
| --- | --- | --- |
| A Fazer | `todo` | Cinza |
| Em Andamento | `in_progress` | Azul |
| Concluído | `done` | Verde |

## Tarefa (Card)

Cada card exibe:

- **Título** — nome da tarefa
- **Prioridade** — badge colorido (`low` / `medium` / `high` / `urgent`)
- **Responsável** — avatar do assignee
- **Prazo** — data de entrega (se definida)
- **Tags** — até 3 `TagBadge` + overflow "+N" (`task.tags`)

## Funcionalidades

- **Criar tarefa** — botão "+" no topo da coluna, com `TagEditor` (envia `tagIds`)
- **Editar tarefa** — clique no card abre modal com detalhes (`TagEditor` + `CommentThread`)
- **Mover tarefa** — drag & drop entre colunas (atualiza status, com rollback otimista)
- **Filtrar** — por responsável, prioridade e tags pessoais (semântica AND: só tasks com **todas** as tags selecionadas)
- **Excluir** — `admin`/`owner` (botão no modal)

## Papéis e permissões

| Criar tarefa | ✅ | ✅ | ✅ |

| Excluir tarefa | ❌ | ✅ | ✅ |
