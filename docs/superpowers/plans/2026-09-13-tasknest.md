# TaskNest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete project & task management SaaS with auth, projects, Kanban boards, member collaboration, and invitations.

**Architecture:** Extend existing TaskNest monorepo (Turborepo + Bun + Vite + React 19 + TanStack Router/Query + oRPC + Drizzle + PostgreSQL + better-auth + shadcn/ui). Add database schemas, oRPC routers, TanStack routes, and shadcn components incrementally.

**Tech Stack:** React 19, TanStack Router/Query/Form, oRPC, Drizzle ORM, PostgreSQL, better-auth, shadcn/ui, Tailwind CSS v4, Lucide React, Zod v4, Bun, Fastify, Turborepo

**Spec:** `docs/superpowers/specs/2026-09-13-tasknest-design.md`

## Global Constraints

- Package manager: Bun 1.4.2
- TypeScript 6.0.3, React 19.2.8
- Zod v4 (catalog version ^4.5.4)
- Drizzle ORM with PostgreSQL
- oRPC for API layer (public + protected procedures)
- better-auth for authentication (email/password)
- shadcn/ui "base-lyra" style, Lucide icons
- Tailwind CSS v4
- Ultracite code standards (no `any`, no `console.log`, arrow functions, `const` by default, optional chaining, nullish coalescing)
- All new DB tables use UUID primary keys via `gen_random_uuid()`
- Cascading deletes on project foreign keys

### Task 1: Database Schema — Projects & Members
Implement `packages/db/src/schema/projects.ts` with `project`, `projectMember` tables and `projectRoleEnum`. Export from `packages/db/src/schema/index.ts`.

### Task 2: Database Schema — Tasks
Implement `packages/db/src/schema/tasks.ts` with `task` table, `taskStatusEnum`, and `taskPriorityEnum`. Export from `packages/db/src/schema/index.ts`.

### Task 3: Database Schema — Invitations
